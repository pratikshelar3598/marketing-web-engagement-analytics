# Marketing & Web Engagement Analytics

## Project Overview
Analyzed marketing campaign performance and web engagement metrics to track trends, user behavior, and key performance indicators.

## Tools & Technologies
- *Database & Querying:* MySQL
- *Spreadsheet Analysis:* Microsoft Excel
- *Data Visualization:* Power BI, Tableau
- *Presentation:* PowerPoint

## Key Highlights & Work Done
- Worked with marketing and web engagement datasets using SQL, Excel, Power BI, and Tableau.
- Built interactive dashboards in Excel, Power BI, and Tableau to visualize performance metrics.
- Prepared presentation slides summarizing key findings and takeaways.

## Files Included
- MARKETING_ANALYSIS PPT.pptx – Analysis presentation
- Marketing_Dashboard.twbx – Tableau packaged dashboard
- MARKETING_PROJECT EXCEL DASHBOARD.xlsx – Marketing Excel dashboard
- PowerBI_DASHBOARD_MAKEING_ANALYTICS.pbix – Power BI dashboard
